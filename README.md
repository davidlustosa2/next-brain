# NextBrain — Site MVP

Site institucional estático, criado com HTML, CSS e JavaScript.

## Execução local

Abra `index.html` no navegador ou execute:

```bash
docker build -t next-brain-site .
docker run --rm -p 8080:80 next-brain-site
```

Acesse http://localhost:8080.

## Deploy

Projeto EasyPanel: `n8n`  
Serviço: `next-brain`  
Porta HTTP interna: `80`  
Branch: `main`

**Nota:** o conteúdo é uma versão de demonstração; cursos, dados de contato e matrículas precisam de validação antes de divulgação comercial.
